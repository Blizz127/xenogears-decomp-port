PSn00bSDK MDEC library (alternate VLC decompressor and support code)
(C) 2022 spicyjpeg - MPL licensed

The game executable incorporates the compressed variable-length-code lookup
table from PSn00bSDK in its opening movie decoder. Source for the covered
port file is provided in pc_port/src/boot_str.c within this source tree. The header is
updated to retain the upstream attribution. The compiled implementation is
identical to the source used for both r7.21 executable builds.
